# 一局消息流原型：雨夜古宅

> 状态：走查后收口版（2026-10-22），对应 消息流原型；用户确认「都按推荐收口」。
> 剧本：`docs/scripts/coc-example.json`（内置《雨夜古宅》）。
> 原型只用于确认呈现，不实现；v1 无 AI，叙述直接用剧本 `narration`。

## 走查结论（2026-10-22）

用户走查后确认按推荐收口：**保留机制骨架，把线索全文收回 KP，拆长消息，隐藏线索总数**。

- 要保留：开团 / 加入 / 开局 / 检定 / 结束 / 战报的机制消息骨架；骰面公开；角色卡私聊；成长群内一行；战报图 + 文。
- 要删掉：场景推进即公开线索全文；`status` 里的「线索 3/4」；把开局、场景、线索合成一条长消息；群内 NPC 名牌。
- 要新增：线索「名称 + lockedSummary」钩子；`unlockedText` 私聊 KP；角色卡群内职业一行；私聊不可达时的回退提示；结束确认 @ 发起人。

一句话结论：骨架已经像跑团，问题在「信息什么时候给」——把线索全文收回 KP，群里只留钩子。

## 怎么读

- 按 QQ 群里的实际阅读顺序排列；时间戳只用来感受节奏。
- `【】` 开头是插件自动发出的机制消息；`阿岚：` 开头是 KP 手打。
- `（私聊 · 某人）` 只有那个人看得到。
- 每步末尾的「未决点」编号 D1–D10 在文末汇总。

## 第 1 步 开团

**谁触发**：阿岚，群内发送。

**输入**
```
阿岚：/trpg start
```

**群内看到**
```
【开团】《雨夜古宅》开始招募
KP：阿岚
剧本：内置 coc-example · 1920 年代 · 调查 · 2–4 人 · 约 60 分钟
发送 /trpg join 加入；发送 /trpg status 查看局面。
```

**私聊**：无。

**未决点**
- 剧本信息给到什么程度？只给题材/人数/时长，还是再给一句简介。简介可能剧透。
- 开团公告要不要 @全体或置顶；本群已有活跃局时失败文案是什么。
- 现在 0 人，公告里要不要写「0/4」。

**私聊不可达时**
- 玩家没收到卡：群内提示「角色卡已私聊，请先私聊 bot 发送任意消息后再试一次」，不公开全文。

**未决点**
- KP 有没有角色卡？指令集 里 KP 是开团者、不 join；`status` 里 KP 这一栏只显示「KP：阿岚」。
- 重复 join、离开后重进、人满时的文案。
- 群内摘要只写职业是否够；要不要写「已就绪」。

## 第 3 步 开局与第一个场景

**谁触发**：阿岚；插件自动接叙。收口后拆成 3 条短消息。

**输入**
```
阿岚：/trpg begin
```

**群内看到（1/3 开局公告）**
```
【开局】《雨夜古宅》开始
KP：阿岚　玩家：小满、老周
```

**群内看到（2/3 场景叙述）**
```
【场景 · 古宅门前】
暴雨把山路冲成了泥河。你们在午夜前赶到沈家老宅，铁门虚掩，门廊的灯忽明忽暗。
门内安静得过分，只有雨水顺着屋檐往下砸。门廊的地砖上，几道泥水痕迹一直延伸到大厅侧门。
```

**群内看到（3/3 线索钩子）**
```
【线索】泥脚印
门廊的泥水痕迹不太对劲。
```

**私聊 · 阿岚**
```
【KP 提示 · 古宅门前】
触发：让雨声和门轴的吱呀声先压住对话，等玩家主动推门。
本场景线索：泥脚印（已解锁）
线索全文（仅 KP）：泥脚印从铁门一直延伸到大厅侧门，但只有进来的方向，没有出去的。脚印边缘有一圈细小的爪痕，不像人鞋。
下一场景：大厅（可用检定：聆听）
```

**未决点**
- 群里的线索钩子用 `lockedSummary`，全文只在 KP 私聊里；KP 可择要口述，也可原文发群。这是本文最大的改动，见 D2。
- 拆 3 条后消息数量变多，但每条更短；手机上不如一条长文那么容易被折叠。
- 叙述由插件直接发，还是私聊阿岚让他复制？v1 无 AI，叙述是剧本模板；直接发省事，但 KP 失去了「讲」的感觉。
- KP 提示合并成一条，还是按「触发/线索/检定」分条；私聊收不到时怎么降级。
- 插件以 bot 身份说「你们」，玩家会不会出戏。

## 第 4 步 检定

**谁触发**：小满、老周；群内自助检定。

**输入**
```
小满：/trpg check 聆听
老周：/trpg check 聆听
```

**群内看到**
```
【检定】小满 · 聆听
1D100 = 34 / 50 → 常规成功

【检定】老周 · 聆听
1D100 = 88 / 50 → 失败
```

**私聊 · 阿岚**
```
【KP 提示 · 聆听】
小满（成功）：声音来自书房方向，中间夹着一声很轻的咳嗽。
老周（失败）：只听见雨声和木梁的呻吟，分不清方向。
```

**未决点**
- 两条检定是否合并成一条「本场景检定」；连续两条在群里像刷屏。
- 骰面和技能值公开吗？34/50 等于公开了小满的聆听值。
- 成功等级用「常规成功/困难成功/极难成功/大成功/大失败」；失败要不要再分普通失败/大失败。
- 检定结果要不要 @ 玩家；玩家自己发的命令，回复要不要带昵称。
- 失败时除了「失败」还给不给一句方向；本原型只给机械结果，方向全靠 KP 提示。

## 第 5 步 线索（大厅）

**谁触发**：阿岚推进场景；插件自动发场景与线索钩子。

**输入**
```
阿岚：/trpg scene 大厅
```

**群内看到（1/2 场景）**
```
【场景 · 大厅】
大厅里点着两盏煤油灯。老管家周福从楼梯阴影里走出来，接过你们湿透的外套，说宅主七天前出门未归。
话音未落，楼上传来一声很轻的拖拽声，像有什么重物在地板上挪动。老管家说，那是风吹动了旧家具。
```

**群内看到（2/2 线索钩子）**
```
【线索】未寄出的信
大厅抽屉里有一封没封口的信。
```

**私聊 · 阿岚**
```
【KP 提示 · 大厅】
触发：读信时只念出「请勿进地窖」，不要解释纸上的水渍。
本场景线索：未寄出的信（已解锁）
线索全文（仅 KP）：信是沈鹤年写给城里警局的：若我三日未归，请勿进地窖。落款日期是七天前，纸面有水渍。
本场景 NPC：老管家周福
下一场景：书房（可用检定：侦查，困难）
```

**未决点**
- 线索钩子里的「抽屉」是 `lockedSummary` 自带的信息，场景叙述里没提；玩家会觉得信息是天上掉下来的吗？
- 同一场景多条线索时怎么排；玩家离开场景后还能不能回看。
- 线索全文收回 KP 后，玩家想自己读原文怎么办？v1 只能等 KP 发。

**私聊 · 阿岚**

```
【KP 提示 · 老管家周福】
公开：六十岁上下，背有点驼，说话很轻，坚持说宅主出门未归。
秘密：他知道祭坛的事，也参与了换命仪式；日记残页上的名字就是他。被逼问时，他会把责任推给宅主。
```

```
书房的门没有锁。壁炉里堆着烧焦的纸，火早就灭了，灰烬还是温的。
墙上挂着沈鹤年的画像，画中人穿着旧式长衫，眼睛的位置被烟熏得发黑。书桌第二层抽屉锁着，钥匙不在锁孔里。
```

```
本场景 NPC：宅主沈鹤年

失败：只有烧焦的纸屑，看不出完整句子。
```

**未决点**
- 插件要不要在群内发「【NPC】老管家周福」这种名牌？收口决定不发，NPC 只以 KP 自由文本出现。
- NPC 的 public/secret 默认都私聊 KP 吗；还是 public 进群、secret 私聊。本原型选「都私聊 KP，由 KP 决定怎么说」。
- 玩家自由对话插件不解析；KP 怎么知道谁在跟谁说话？只能自己看群。
- 要不要给 KP 一条「当前场景/线索/NPC」的常驻面板（私聊或群内置顶）。
- 场景推进后线索钩子已经公开，但「侦查」检定仍可能让线索全文由 KP 口述；检定与线索的关系留给 呈现规范/规格装配。

**谁触发**：阿岚；同一条命令发两次确认。

**输入**
```
阿岚：/trpg end
```

**群内看到**
```
【结束确认】确定结束《雨夜古宅》吗？@阿岚
30 秒内再次发送 /trpg end 确认；超时自动取消。
```

**输入**
```
阿岚：/trpg end
```

**群内看到**
```
【结束】《雨夜古宅》· 结局「雨夜脱身」
你们没有下到地窖最深处。天亮前，雨停了，你们带着那封信和烧焦的日记离开古宅；身后的门自己关上了。

【成长】小满 聆听 50 → 52（成长检定 1D100=78 > 50，+1D10=2）
【战报】正在生成……
```

**私聊 · 小满**
```
【角色卡更新】聆听 50 → 52
```

**私聊 · 老周**：无（本局没有技能成长，不单独提示）。

**未决点**
- 二次确认 @ 发起人；30 秒内别人也能发 /trpg end 会怎样（指令集 允许 KP 或群管发起）。
- 结局叙述公开是否剧透（旁观者、以后想玩同一剧本的人）。同群能否重复开同一剧本？
- 成长公开还是私聊：本原型群内一行、私聊卡更新；失败玩家不单独提示。
- 结束摘要与战报的顺序；战报生成失败时是否重试。

## 第 8 步 战报

**谁触发**：插件异步生成；先图后文。

**群内看到**
```
［图片：战报 · 《雨夜古宅》 · 2 小时 06 分 · 结局「雨夜脱身」］
```

图片生成成功后附一条文字摘要；生成失败则只发文字（数据模型与存档 的回退）：

```
【战报】《雨夜古宅》
KP：阿岚　玩家：小满、老周
线索：泥脚印、未寄出的信、烧焦的日记
检定：2 次（成功 1 · 失败 1）
成长：小满 聆听 +2
日志：/trpg log 可查看本局记录（保留 30 天）
```

**未决点**
- 图、文是两条还是一条；只发图会不会没人点开。
- 收口决定不 @ 参与者；是否同时发群文件留给 呈现规范。
- 战报字段：时长、场景数、线索、检定次数、成长、结局；未解锁线索和 NPC 秘密绝不能出现（scripts/README 已写死）。
- 图片渲染失败的文案；30 天后 log 失效的提示。
- 战报是否算「公开剧透」：旁观者在群里能看到结局与线索。

## 走查记录（已填）

- 要保留：机制消息骨架、骰面公开、角色卡私聊、成长群内一行、战报图 + 文。
- 要删掉：场景推进即公开线索全文、status 的线索总数、合成一条长消息、群内 NPC 名牌。
- 要新增：线索名称 + lockedSummary 钩子、unlockedText 私聊 KP、角色卡群内职业一行、私聊不可达的回退提示、结束确认 @ 发起人。
- 一句话结论：骨架像跑团，问题在信息什么时候给；线索全文收回 KP 后，群里留下的是钩子而不是答案。
